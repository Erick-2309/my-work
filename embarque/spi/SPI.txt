Résumé complet sur SPI (Serial Peripheral Interface)
1. Qu’est-ce que SPI ?
SPI est un protocole de communication série synchrone.
Il permet un échange de données rapide entre un maître (master) et un ou plusieurs esclaves (slaves).
Il est très utilisé dans l’électronique embarquée (capteurs, mémoires, écrans, etc.).


2. Les lignes de SPI
MOSI (Master Out Slave In) : ligne de données du maître vers l’esclave.
MISO (Master In Slave Out) : ligne de données de l’esclave vers le maître.
SCLK (Serial Clock) : horloge fournie par le maître pour synchroniser la communication.
CS (Chip Select) ou SS (Slave Select) : sélectionne l’esclave actif (niveau bas actif généralement).


3. Fonctionnement
Le maître active la ligne CS du périphérique esclave pour commencer la communication.
Il génère une horloge SCLK.
Sur chaque front d’horloge (montant ou descendant, selon mode), un bit est transféré simultanément sur MOSI et MISO (full duplex).
Le protocole est full-duplex (on peut envoyer et recevoir en même temps).


4. Modes SPI
Le mode SPI est défini par deux paramètres :
CPOL (Clock Polarity) : niveau logique de l’horloge au repos (idle)
CPOL=0 → horloge au repos à 0 (bas)
CPOL=1 → horloge au repos à 1 (haut)
CPHA (Clock Phase) : moment où les données sont échantillonnées
CPHA=0 → données lues au premier front d’horloge (front montant si CPOL=0)
CPHA=1 → données lues au second front d’horloge

Mode SPI.      CPOL  CPHA	Description
   0		0	0	Horloge idle bas, front montant
   1		0	1	Horloge idle bas, front descendant
   2		1	0	Horloge idle haut, front descendant
   3		1	1	Horloge idle haut, front montant



5. Caractéristiques importantes
Transfert bit à bit (minimum 1 bit par cycle d’horloge).
Vitesse élevée : plusieurs Mbps possibles (selon matériel).
Nombre de fils : minimum 4 (MOSI, MISO, SCLK, CS).
Communication full duplex.
Protocole simple, très répandu.


6. Avantages
Communication rapide et synchronisée.
Full duplex.
Contrôle facile grâce à la ligne CS.


7. Inconvénients
Nécessite plusieurs fils.
Pas de gestion d’erreurs intégrée (contrairement à UART).
Le maître doit gérer la sélection des esclaves.



| Élément | Ligne SPI       | Rôle                         |
| ------- | --------------- | ---------------------------- |
| Start   | CS = LOW        | Active l’esclave             |
| Clock   |   SCLK.         | Cadence la communication     |
| Données |   MOSI / MISO   | Envoi et réception bit à bit |
| End     |   CS = HIGH     | Termine la trame             |
