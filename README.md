# My Work



Dépôt regroupant mes travaux pratiques et projets réalisés pendant ma formation. 

## Contenu

| Dossier | Description |
|---|---|
| `cpp/` | TP de programmation C++ (pointeurs, classes, héritage, ...) |
| `qt/` | TP d'interfaces graphiques avec Qt |
| `traitement-image/` | TP de traitement d'image (filtrage, seuillage, ...) |
| `embarque/` | TP de systèmes embarqués : UART, I2C, SPI, ADC, Arduino |
| `Python/` | Scripts et TP en Python |

## Compétences mises en pratique

- **Langages** : C++, Python, C/Arduino
- **Interfaces graphiques** : Qt
- **Protocoles de communication** : UART, I2C, SPI
- **Acquisition de signaux** : ADC, utilisation d'un GBF
- **Traitement d'image** : [OpenCV, etc.]

## Matériel et outils

- Cartes : [Arduino Uno, STM32, .STM8.., ESP32]
- IDE : [Qt Creator, Arduino IDE, ...]
- Instruments : GBF, oscilloscope, [...]


## Compiler et lancer

- **Projets Qt** : ouvrir le fichier `.pro` avec Qt Creator, puis compiler et exécuter.
- **Projets Arduino** : ouvrir le fichier `.ino` avec l'Arduino IDE, sélectionner la carte et téléverser.
- **Scripts Python** : `python nom_du_script.py`
